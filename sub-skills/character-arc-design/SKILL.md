# 角色与关系设计（步骤 50–67）

角色设计服务于连续选择、关系变化和长期回报，而不只是人物档案。

## 覆盖步骤

50. 主角基本信息；51. 性格特点；52. 核心机制/金手指与成本；53. 核心动机；54. 背景故事；55. 成长弧线；56. 创建主角设定文件。
57–63. 按 workflow-config（默认 7）并行提出配角的功能、独立欲望、与主角互相改变、知识边界和出入场窗口；
64. 幕后大 Boss；65. 并行提出 2–3 个中期反派；66. 并行提出 3–5 个前期反派；67. 关系网络、冲突触发器和变化条件。

## 人物卡

为每个关键角色在 01-canon/characters/<id>.md 登记：公开身份、真实欲望、当前目标、恐惧、资源、代价、秘密、知识边界、说话/行动特征、关系、起点—转折—终点、能迫使他改变的事件。主角另写入 protagonist.md；核心机制/金手指必须引用 power-system.md 的限制和反制。

关系不是静态箭头。对每一关键关系写明：双方以为对方是什么、实际依赖/冲突什么、何事可改变关系、改变后的代价。

## 自检

- 主角的关键胜利来自选择而非作者赠予；
- 配角可以拒绝主角，也有不围绕主角的目标；
- 反派的强度与动机能持续升级；
- 谁知道什么、何时知道、依据是什么可以被时间线审计。

人物长期弧线由 long-arc-planning 编排；本 Skill 只提供可提交的角色与关系基础。
