# 力量体系（步骤 35–37）

将力量写成冲突预算，而不是升级名词表。适用于修行、异能、科技、职业技能、权力与资源体系。

## 覆盖步骤

35. 等级、门槛、身份或资源准入，以及每档的可见差异；
36. 能力、训练、资源、协作与对抗关系；
37. 限制、代价、失控、反制和信息边界。

## 产出

为每一能力/等级给出：获得条件、能做什么、不能做什么、消耗、风险、克制关系、旁观者如何判断、至少一个适合场景化展示的试炼。将结果写入 01-canon/power-system.md 候选区。

主角优势必须同时具备可被利用的弱点或压力。反制不必平均，但要可推理，不能到危机时临时增加新规则。

## 自检

- 低阶/弱者是否仍可通过情报、环境、关系或代价获得行动空间；
- 升级是否改变角色面对的问题，而非只提高数字；
- 胜利是否有可追溯的资源来源与代价；
- 能否用三场不同类型的冲突检验该系统。

输出与世界、势力、谜案的依赖/冲突，交给 canon-management 合并。
