# 第 15 章：丙炉吐灰

- 细纲版本：Canon 1.0.14
- 状态：锁定

锈闸一响，阿绳先烧得说不出话来。

他靠在芦窝最深处，额头烫得吓人。顾青梧掀开包扎的布，伤口周围已红得发亮。她摸出最后一包止血散，停了一瞬。

“会疼。”她说，“也可能压不住热。你同意我现在用？”

阿绳连点头的力气都不够，只抬了抬手指。

顾青梧把药撒下去。阿绳的背猛地弓起来，牙关咬得咯咯响，阿桃赶紧把孩子抱远。祝离将死籍包在干草里，低声道：“闸开了。”

旧沟尽头的铁链拖过石槽。第一股灰水涌出来时，水不是黑的，而是灰白，里面卷着未烧尽的纸屑、灯芯末和碎盐壳。水一到浅处便冒泡，像有无数细小的骨头在沟底翻身。

“我下去。”陆沉舟说。

“只到那块石头。”顾青梧道，“灰水会咬伤。”

陆沉舟点头，拿起梁瘸子递来的破芦筛，踩进沟边。水立刻没过脚踝，冰冷的灰泥从鞋缝钻进去。他不敢往闸门方向看，只把筛子横在水流下方。纸灰碰到筛眼，大半化成糊，小半被芦丝截住。

第一筛，只有断灯芯。

第二筛，一截铜皮和一团烧焦的麻绳。

第三筛，有东西卡在芦丝上，薄得几乎和灰糊融在一起。陆沉舟伸手去捏，指尖碰到半枚朱印的硬边。

西四收验。

他心口一紧。那是炭化的纸签，正面只余几个断字，背面却被火熏出深褐色的印痕。他刚要把筛子抬高，远处忽然有人喊：“下游堵了没有？”

灰窑巡闸的声音。

祝离在芦窝里敲了两下石头。别动。

陆沉舟半蹲在灰水里，眼看一张更完整的黑纸从上游飘来。纸上似乎有整行字，边缘没有烧透。只要他往前两步，就能捞到。

可那张纸正往闸边流，巡闸的人沿岸一走便会看见他。手里这块半印残签已经够和旧转签、废油条比对；那张完整纸是机会，也是把所有人拖回盐路的钩子。

陆沉舟看着它从筛旁漂过，没有追。

他把炭签按进衣襟，往芦窝退。

“谁在那边？”灰工已经走到沟岸上。

祝离拉下芦叶。梁瘸子扶住阿绳，阿桃把孩子按进怀里。顾青梧则把药囊摊在身前，像一个被闸水困住的医修。

灰工停在几丈外，鼻子动了动。“药味？”

“灰水冲了伤口。”顾青梧从芦里走出半步，“我在看能不能止血。你若要把人赶走，先把这条命接过去。”

她说得很硬，手上却还沾着阿绳的血。灰工看到她的医修小印，又看到沟里翻滚的灰，显然不想接这个麻烦。

“这里不能留人。”

“我也不想留。”顾青梧道，“伤者不能走。”

“谁让他在下游翻灰？”

“他没翻。”顾青梧说，“是我。”

灰工皱眉：“你翻什么？”

“看灰水会不会伤人。”

“灰窑的水还能伤谁？”

顾青梧把沾灰的纱布举起来：“那你替我写一句不伤。我带回去给伤者看。”

灰工被噎住，骂了一声，挥手道：“午后之前滚远点。”

他走开前，又盯了沟底一眼。灰水还在冲，那张完整的黑纸早已不见。陆沉舟直到脚步声远了，才把炭签取出来。

顾青梧先替他冲掉手上的灰泥。灰水果然咬得皮肤发红。

“你捞到了什么？”

陆沉舟把纸摊在一只旧瓷片上。祝离用灯罩挡风，阿绳在草垫上睁开眼，勉强看过来。

炭签被水泡软，顾青梧用细针挑开烧焦的边。西四收验的半印在左上，下面能辨出“劫乙七”，再往下是“丙炉”。最后四个字最清楚，像被人特意压得很深。

不入总灰。

陆沉舟把灰窑交接签取出。上面同样有“灰窑丙炉，不得混灰”。再放上洗油房的分样条，乙七两个字在不同纸上、不同墨色里彼此对着。

北堤。

西四。

丙炉。

同一个劫字号走过三处，最后连灰都不能和别的灰混在一起。

“这能说明什么？”阿绳问。

“说明有人不想让它和别的东西混。”陆沉舟说。

“为什么？”

“还不知道。”

他没有把“不知道”说得轻。炭签不是答案。可他们如今有了两处签字、一份分样和一页死籍的时辰矛盾。有人想把它们拆开，洗掉，烧掉；他们便一点点把它们摆到一起。

阿绳的热还没退。顾青梧收起最后的伤药，药囊一下轻了许多。

“不能再藏水边。”祝离说，“也不能让阿绳这样熬。”

灰工的声音又在上游响起：“谁在下游捞过丙炉的灰？”

这一次，比刚才近。
