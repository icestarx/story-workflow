# 《万劫照骨书》前二十章质量评审

## 范围与方法

- 范围：第一章至第二十章正文、对应细纲、人物/谜案/力量/读者体验 Canon、时间线，以及逐章与两次批次审校。
- 方法：技术审计、Canon/回归校验、主审抽读与三份相互独立的审读（连载体验、人物文笔、悬疑连续性）。无外部读者样本，因此不把推测写成读者共识。
- 自动结果：20 章齐全；禁用项、重复段落、高频句首与既配置表达模式均无命中；回归套件通过。自动通过不等同于叙事质量通过。

## 总结结论

这是一个开篇承诺明确、证据纪律难得严谨的“制度仙侠悬疑”起步：第一章以阿七命灯、子初/丑正矛盾和照骨书失去父亲笑声，迅速立住谜案、代价与情感债；第二十章以七日封档和“未生暂置”完成了从一盏灯到一份旧籍的阶段升级。

当前最需要修复的不是因果断裂，而是**交付密度与体验多样性**：第十一章后正文显著变短，尤其第十三至第二十章多以程序性对峙推进；照骨书的不可逆代价在首章后长期没有重新改变角色关系或行动方案。若不处理，下一批容易从“仙侠悬疑”滑向“高质量文书追索”。

## 已验证优势

1. **主角的选择弧线清楚。** 第一章陆沉舟为了残响失去父亲笑声；第六章不追劫务车以免牵连后荡；第十三章不抢小铜灯；第十五章不追完整黑纸。它们将“先保人和可互证的链条”写成重复可见的选择，而非口号。
2. **顾青梧、祝离、阿绳各有稳定的伦理动作。** 顾以同意和留样建立医修声音；祝离的“先问称呼”使守名主题具有人味；阿绳在第十、十一、十六、十八、十九章表达可用与不可用的边界，避免沦为方便证人。
3. **程序不是纯背景。** 第六章拒验条、第十章分样、第十八章潮标抄记、第二十章封档记，都把弱者无法直接发言的处境转化为可追责痕迹；这是本书区别于单纯查案或升级流的核心竞争力。
4. **能力未越权。** 照骨书只给债向与残响；潮标、盐砂、旧签和口供承担验证责任。第十一章、十六章、二十章均主动保留“不足以定案”的边界，连续性可靠。

## 问题、证据与处理建议

### S1｜时间线记录跨日错误，须在下一次正文生产前修复

- 位置：`正典/时间线.md` 第十八至第十九章。
- 证据：第十八章明示“午后的潮已退”，章末季衡预告“明日卯时，封顾青梧药囊”；第十九章随即承接封验，但时间线仍登记为“坠月历3127年霜降日卯后”，漏记“次日”。
- 影响：正文承接无明显矛盾，但 Canon 时间线会把午后事件之后的“明日卯时”错误折回同日清晨；继续写作时会污染阿绳伤势、三日复核和七日封档的倒计时。
- 建议：经 canon-management 做最小 Canon delta，将第十九章时间改为“坠月历3127年霜降次日卯时（或卯后）”，再回归验证。此项是记录修正，不应改写已锁定正文。

### S2｜第十一章后篇幅急降，细纲字数预算没有兑现

- 证据：前十章平均 3,416 字；后十章平均 1,859 字。第十四章正文 1,286 字，细纲预算 3,500–4,000 字；第十七章正文 1,754 字，预算 3,200–3,800 字；第二十章正文 1,740 字，预算 3,500–4,000 字。第十三至第二十章均低于 2,000 字。
- 影响：第十四章灰渠撤离、第十五章丙炉取灰、第十七章验盐、第十九章封验、第二十章问籍的场景功能都成立，但转折、身体反应、对手反制和余波被压缩，二十章阶段兑现显得小于前十章蓄积的压力。
- 建议：不要用解释或额外文书填字数。若作者决定返修，应优先扩写第十四、十五、十七、十九、二十章的行动阻力、角色选择和结果余波；每章至少补足一个不可替代的现场目标或关系冲突。

### S2｜程序场景从“反用规则”变成可预测的重复节拍

- 证据：第十六至二十章连续遵循“带纸/样物入程序场 → 对方限缩或拒绝 → 顾青梧要求署名/留痕 → 得到较小纸面成果”的结构：公示单、拒答条、潮标抄记、封验附件、封档复核。
- 影响：事实层层升级，但动作与即时情绪回报相近；“写下来”“那就写”“留一条”等职业语感外溢，削弱人物台词区分。
- 建议：第二十一至二十四章至少安排两种非文书推进：实地寻人/潮汐逃脱、队伍安全方案冲突、命火或契印资源反制。文书应成为行动后的武器或后果，而不是每章主场景。

### S2｜照骨书与仙侠力量线长期沉默

- 证据：第一章的照见换走父亲笑声是最强的私人代价；之后第六至第二十章基本只以“不得滥用”维持规则。引烛、命火、契印、见证等体系没有在危机中出现可观察效果、消耗和反制。
- 影响：本书的证据优先原则是优点，但书名、首章与题材承诺会让读者期待“有代价的仙侠术法如何改变查案”；长期沉默会降低题材辨识度和主角的主动爽感。
- 建议：在下一小段只复用一次照骨书，并事前明确它能看什么、会忘掉什么、会伤及哪段关系；让结果改写行动计划，而非直接给答案。同步让顾或对手以可反制、会消耗的术法参与一场非纸面冲突。

### S3｜反向解释与对手主动性不足

- 证据：从北堤到西四、洗油房、灰窑、验盐、旧籍，新物证大多精准指向下一站；第十一章虽说“两张纸不能说明同一件事”，但“疫潮旧例/自然盐路污染/邪修祭祀”等替代解释未获得充分的人物押注与验证成本。
- 建议：让“未生暂置”至少存在两条可辩解释，并让季衡或盐课公开选择其一；主角需承担一个可见代价才可排除。季衡还应出现一次会伤及自身利益的具体选择，而不仅是盖印、拒答与递预告。

### S3｜人物的下一步应从“守边界”升级为“提出条件”

- 陆沉舟：再次让记忆代价在祝离或顾青梧关系中产生当下后果，而不只是回忆父亲。
- 祝离：给一次与陆不同、会改变行动路线的主动判断，避免后段退为“守死籍/解释纸义”。
- 阿绳：让他以安全条件、同工或交换目标提出一个会改变队伍计划的方案，保持其拒绝权但增加能动性。
- 季衡：给出可观察的自保计算、可追责失误或真实损失；不必提前揭示完整动机。

### S4｜第十九至第二十章的“三日”可增加一笔状态承接

- 证据：第十九章设定三日后复核，第二十章直接开堂。阿绳伤势、藏身转移与季衡在三日中的反制只能从结果推断。
- 建议：后续以一两笔回顾落地这些变化，使七日封档成为正在收紧的现实压力；不必另加过场章。

## 供下一批执行的优先次序

1. 先修复 S1 时间线，重跑 Canon 与回归校验；未修复前不得开始第二十一章。
2. 作者决定是否重开第十三至第二十章做“补场景、不注水”的篇幅返修；这会影响已锁定正文，须走修订与影响追踪。
3. 若直接写第二十一章，先锁定三条执行约束：每两至三章至少一次非文书主冲突；一次有关系后果的照骨书使用；阿绳、祝离或季衡各有一次改变路线的主动选择。
4. 后续质量门须把“细纲预算兑现率”和“相邻章节时间线转移”纳入自动审计；这是本次 workflow 改进的首要证据。

## 审校结论

- 叙事质量：具备继续连载的核心吸引力，尤其是人物伦理、制度压迫与证据链；不建议推倒重写。
- 生产状态：因时间线 S1，下一批正文应暂停在修订门外；其余为可计划的 S2/S3 提升项。
- Canon 决策：除时间线最小修正外，所有建议均为候选创作调整，不进入 Canon。
