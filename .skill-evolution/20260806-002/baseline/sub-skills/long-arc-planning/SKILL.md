# 全书系统设计（步骤 79–87）

本 Skill 为宏观结构建立可审计的长线账本，使情绪、爽点、角色、伏笔与反转能跨卷追踪。

## 覆盖步骤

79. 情绪弧线和压力递进；80. 爽点节奏、兑现与代价；81. 主角成长弧线；
82. 并行设计关键配角成长弧线；83. 并行设计反派演变过程；
84. 长期伏笔（300+ 章项目默认目标 30–50）；85. 中期伏笔；86. 短期伏笔；87. 反转点、前置证据、造成的行动/认知后果。

## 产出

写入 规划/长线系统.md，并同步提议更新 正典/伏笔台账.md。长/中/短伏笔必须分区登记；长期数量是篇幅匹配的目标而非盲目配额。每条长线用稳定 ID 记录：起点、推进节点、兑现点、依赖、代价、风险、相关卷章、当前状态、责任人/章节。

反转登记必须写“读者先前合理相信什么、看见过什么证据、改变后什么行动不再可行或必须发生”。没有前置信息的揭露只是惊吓，不算反转设计完成。

## 门禁

- 每条关键伏笔都有首次出现、至少一次推进和计划回收窗口；
- 每个主角弧线的变化能被具体选择验证；
- 情绪释放前有积压，释放后有后果；
- 反转不能推翻已锁定的可观察事实。
