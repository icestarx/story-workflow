# 全局 Review（步骤 119–125）

在全书细纲完成后、正文批量生产前执行一次完整审计；这不同于每 10–20 章的 serial-review。

## 覆盖步骤

119. Review 全书大纲；120. Review 各卷卷纲；121. Review 所有细纲；122. Review 伏笔系统；123. Review 角色设定；124. Review 世界观设定；125. 输出全局 Review 完成结论。

## 流程

先运行 run_regression_suite.py；再按 [创作团队职责](../../references/editorial-board.md) 与 [流行长篇编辑标准](../../references/editorial-standards.md)，由故事架构、人物、连载、连续性与文字席位分别检查 Canon、因果、承诺、节奏、人物和伏笔。每项意见都写位置、证据、影响、S1–S4、责任席位/步骤和处理状态。

在 审校/global-review.md 输出一张六项覆盖表和决策清单。S1 必须清零；S2 必须修复或取得作者延期决定，才能进入阶段 6。

## 边界

Review 只提出修订和影响；涉及 Canon 的改变交 canon-management 提交。不要因追求“整齐”抹平有意的悬念、复杂关系或题材差异。
