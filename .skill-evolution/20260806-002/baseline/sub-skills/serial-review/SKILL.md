# 连载周期复盘

在每 10–20 章、每卷结束、重大改设或收到集中读者反馈后使用。复盘不是重写大纲的借口，而是为下一周期提供有优先级的决策。

## 输入

读取本周期章节、审校报告、Canon、卷纲、长线账本和可验证的反馈样本。将读者反馈分为事实错误、共识体验、偏好分歧和噪声；不要把单条意见直接写入 Canon。

## 检查

- 卷首/周期承诺是否兑现，读者为何继续读；
- 节奏、场景功能、情绪和爽点是否重复或失衡；
- 主线、支线、角色弧线、秘密、伏笔的推进率；
- 状态、时间线、知识边界和能力成本是否漂移；
- 下一周期最大的风险、机会和需要用户决定的事项。

## 输出

在 审校/period-<range>.md 输出证据、优先级、建议、影响范围、是否需 Canon 决策。结论应指向可执行的下一卷/章节调整，而非泛化评价。
