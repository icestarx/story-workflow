# 发布包装（可选）

将已确认的读者承诺翻译为书名、简介、标签和发布清单；不承诺流量，也不把包装改成与正文不一致的内容。

## 产出

保存于 发布：3–10 个书名方向、不同长度简介、标签/关键词、首卷/章节标题、读者承诺核对、发布前敏感项与版本记录。

简介必须说明主角、异常处境、目标、主要阻力和独特承诺，避免空泛形容词和剧透终局秘密。标签要反映真实内容和边界。

## 边界

- 任何平台规则、广告法、AI 内容标记或审核要求需用 story-research 核验当前版本；
- 不虚构成绩、评论或平台推荐；
- 不因包装需求修改 Canon 或正文结局，除非走正式变更流程。
