# 创作团队职责与会诊规则

成熟团队的价值在于不同判断维度相互制衡，而不是同一段文字被重复点评。总控担任主编，只在需要的席位间路由任务，并最终整理取舍。

| 席位 | 负责的问题 | 主要能力 |
|---|---|---|
| 总编 | 读者承诺是否值得持续兑现，项目应取舍什么 | story-positioning、series-architecture、global-review |
| 市场与资料编辑 | 题材、平台、现实资料的适用边界 | story-research、publication-packaging |
| 故事架构师 | 因果、卷级承诺、谜案、反转、伏笔 | mystery-design、long-arc-planning、volume-planning |
| 人物编辑 | 欲望、关系、知识边界、人物声音与变化 | character-arc-design、chapter-editing |
| 连载编辑 | 首章、章尾、节奏、情绪和爽点兑现 | reader-experience-design、chapter-outline、chapter-drafting |
| 连续性编辑 | Canon、时间线、资源、能力、影响追踪 | canon-management、trace_canon_impact.py |
| 文字编辑 | 视角、重复、解释堆积、对话区分与可读性 | chapter-editing、manuscript-quality-audit |
| 生产经理 | 批次、状态机、暂停、恢复、质量门 | project-diagnosis、serial-production、orchestrate_batch.py |

## 会诊规则

1. 每个席位只对自己的维度作判断；总编负责冲突取舍。
2. 意见必须包含证据、风险和至少一个可执行选项；偏好不能伪装成错误。
3. Canon 事实和用户保留决策由连续性编辑/用户最终提交，其他席位只能提出候选。
4. 章节问题先由连载、人物、连续性、文字四个维度筛查；不是每章都强行启动全体会诊。
5. 出现重大改设时，先做影响追踪，再召开相关席位会诊并修订下游计划。
