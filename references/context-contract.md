# 章节上下文包契约

上下文包只拿当前章节必需的信息，避免把整部小说塞入写作上下文后稀释重点。compile_chapter_context.py 支持 draft、revise、audit 三种用途，默认组合：

1. 项目简报与风格卡；
2. 目标章节的锁定细纲；
3. 最近 1–2 章正文末段（首章除外，可配置）；
4. 全局上下文追踪、当前状态、时间线末段、活跃伏笔；
5. 世界和力量的硬规则；
6. 章节索引；
7. 细纲中以 [[canon.id]] 标记的实体/事实对应源文件。

写细纲时，用 [[char.hero]]、[[faction.night]]、[[mystery.case01]] 等 ID 显式标注所需 Canon；可用 `--include-id` 补充。缺失 ID 会在上下文包中列为警告；受控自动生产必须带 `--fail-on-warning`，在写正文前解决或降为 TBD。

每个文件会按字符上限截取；被截断内容需回到源文件核对。包头记录用途、Canon 版本和显式引用，作为章节输入快照。上下文包是可再生成的工作产物；01-canon/context.md 则记录已确认的全局创作位置和硬约束，应由 canon-management 维护。
