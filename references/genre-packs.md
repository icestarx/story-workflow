# 题材包：把网文规律转成可验证约束

题材包是可选的创作检查表，不是公式。先服从项目定位与读者承诺；当某条惯例与作品的差异化冲突时，明确写出取舍与补偿机制。

## 玄幻 / 仙侠 / 高武

- 首卷尽早让读者看见力量规则、主角缺口、第一笔可望而不可得的资源与可付代价；
- 升级要改变对手、社会位置、决策难度或关系，而非只提高数值；
- 资源、功法、法器、秘境等爽点须有来源、竞争与后果；
- 大境界跨越前，把限制、训练、失败或情报铺在可见场景里；
- 反派/势力应有资源与制度逻辑，不能无限按批次投放。

## 悬疑 / 推理 / 灵异悬疑

- 每个案件明确表层问题、真实机制、可见证据、误导来源、答案与后果；
- 读者应该可以基于已有信息提出合理猜测，不能靠结尾新增规则翻盘；
- 超自然能力提供有限信息或新风险，而不能替代调查和判断；
- 线索出现、误读、重释和回收要登记责任章节；
- 紧张不只靠死人/反转数量，也来自期限、代价、信息差和角色关系。

## 都市 / 职场 / 现实成长

- 职业或行业细节服务行动目标、利益冲突和评价体系；
- 资源、人脉、规则、舆论和法律边界要影响胜负；
- 打脸或逆袭前建立轻视、约束和风险，胜利后留下真实关系/职业代价；
- 避免将专业人士写成只为衬托主角的工具人。

## 言情 / 情感向

- 感情推进来自价值、目标、信任和边界的变化，不只来自误会与肢体接触；
- 每位情感关系中的人物保留独立目标、拒绝权和成长线；
- 高糖、拉扯、和解或分离要有情绪前因和关系后果；
- 读者承诺须说明感情线在主线中的位置与结局边界，避免误导标签。

## 科幻 / 末世 / 无限流

- 先让读者理解可观察规则、资源匮乏和失败代价，再展示复杂设定；
- 副本/任务必须改变主线资源、关系、秘密或世界理解，不能只重复通关；
- 信息揭示按“问题—实验/行动—结果—更大问题”递进；
- 技术、系统或规则应有失效、滥用与反制，避免万能工具。

## 融合题材

选一个主承诺和一个增强承诺。例如“悬疑为主、修行规则为增压”，则谜案的公平性优先于能力展示。用 brief.md 写清优先级，出现冲突时据此裁决。
