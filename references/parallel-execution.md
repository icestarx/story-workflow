# 并行化执行指南（200万字支撑版）

## 核心原则
1. **全局一致性**：每一步都要检查是否符合全局框架
2. **动态章节数**：根据项目大小动态计算总章节数
3. **并行化执行**：识别可并行的步骤，提高执行效率

## 并行化标识

### 1. 项目初始化阶段
- **步骤4**：并行读取10个参考文件
- **并行度**：10个文件同时读取
- **执行方式**：一次性并行读取所有参考文件

### 2. 核心设定阶段
- **步骤38-44**：并行设计多个配角

- **执行方式**：每个配角独立设计，互不影响

- **步骤45**：并行设计多个反派
- **并行度**：3-5个反派同时设计
- **执行方式**：每个反派独立设计，互不影响

- **步骤71-73**：并行创建配角设定详细文件
- **并行度**：5-7个配角同时创建
- **执行方式**：每个配角独立创建，互不影响

- **步骤74**：并行创建反派设定详细文件
- **并行度**：3-5个反派同时创建
- **执行方式**：每个反派独立创建，互不影响

### 3. 大纲搭建阶段

- **执行方式**：每个反派独立设计，互不影响

### 4. 细纲设计阶段

- **并行度**：5-10章/批
- **执行方式**：每批细纲独立设计，互不影响
- **动态调整**：根据总章节数动态调整批次

### 5. 正文写作阶段
- **步骤129-135**：并行写作各章正文
- **并行度**：2-3章/批
- **执行方式**：每批正文独立写作，互不影响

- **步骤137-140**：并行检查各章质量
- **并行度**：20章/批
- **执行方式**：每批质量检查独立进行，互不影响
- **动态调整**：根据总章节数动态调整批次

## 并行化执行策略

### 1. 批次划分
```
批次大小 = 并行度 × 批次数
- 细纲设计：5-10章/批
- 正文写作：2-3章/批
- 质量检查：20章/批
```

### 2. 执行顺序
```
1. 确定总章节数
2. 计算批次数
3. 按批次并行执行
4. 每批次完成后检查全局一致性
5. 继续下一批次
```

### 3. 全局一致性检查
```
每批次完成后，检查：
- 角色关系图谱框架
- 伏笔系统架构
- 情绪弧线总图
- 力量体系框架
- 世界观框架
- 悬念系统架构
```

## 动态章节数支持

### 1. 计算总章节数
```
总章节数 = 总字数 ÷ 每章字数
- 200万字 ÷ 4000字/章 = 500章
- 150万字 ÷ 4000字/章 = 375章
- 100万字 ÷ 4000字/章 = 250章
```

### 2. 计算批次数
```
细纲设计批次数 = 总章节数 ÷ 5-10章/批
- 500章 ÷ 10章/批 = 50批
- 375章 ÷ 10章/批 = 38批
- 250章 ÷ 10章/批 = 25批

正文写作批次数 = 总章节数 ÷ 2-3章/批
- 500章 ÷ 3章/批 = 167批
- 375章 ÷ 3章/批 = 125批
- 250章 ÷ 3章/批 = 83批

质量检查批次数 = 总章节数 ÷ 20章/批
- 500章 ÷ 20章/批 = 25批
- 375章 ÷ 20章/批 = 19批
- 250章 ÷ 20章/批 = 13批
```

### 3. 动态调整
```
如果某批次发现全局一致性问题：
1. 暂停后续批次
2. 修正问题
3. 重新检查全局一致性
4. 继续后续批次
```

## 注意事项

1. **并行化不是必须的**：如果并行化会导致全局一致性问题，可以改为串行执行
2. **批次大小可以调整**：根据实际情况调整批次大小
3. **全局一致性检查是必须的**：每批次完成后都要检查全局一致性
4. **动态调整是必须的**：根据实际情况动态调整参数
