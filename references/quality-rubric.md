# 质量门禁与审校量表

质量不是单一分数。任何锁定前的检查依次经过结构、Canon、叙事/体验、语言四道门；前一道失败时，后一道意见不得掩盖问题。

## 四层门禁

| 层级 | 必查项 | 失败后处理 |
|---|---|---|
| 1. 结构 | 文件命名、细纲字段、章节覆盖、字数预算 | 补全或修复结构 |
| 2. Canon | 时间、地点、资源、能力、知识边界、伏笔 | 阻断锁定，提交冲突 |
| 3. 叙事体验 | 因果、动机、承诺、压力、情绪、爽点、章尾 | 重写或记录作者取舍 |
| 4. 语言编辑 | 视角、重复、说明堆积、句式、对话、节奏 | 定向润色 |

## 严重级别

| 级别 | 含义 | 默认处理 |
|---|---|---|
| S1 | Canon 冲突、角色越知、因果断裂、缺失锁定细纲、关键承诺无法兑现 | 阻断，必须修复或撤回 |
| S2 | 动机不足、场景无结果、伏笔责任缺失、重大节奏/体验失衡 | 修复，或记录延期理由与风险 |
| S3 | 描写重复、转场生硬、局部信息与表达不足 | 建议修复 |
| S4 | 偏好性文风/题材选择 | 作者决定，不作为错误 |

## 有效审校意见

每条意见都写：位置或事件、观察到的证据、影响、严重级别、最小修订方向、修订后要复查的项目。

有效：第 4 场中主角直接判断密信来源，但 state.md 显示他尚未获得笔迹样本（S1）；可改为怀疑并安排取得样本的行动，随后复查谜案线索责任。

无效：更有张力、去 AI 味、文笔再润色。此类意见必须补充事实、位置和修改方向，才可纳入报告。

## 分数的有限用途

如需要纵向观察，可分别记录 Canon、因果人物、节奏体验、语言四项 0–10 的诊断分，并附证据。总分不能覆盖 S1/S2，也不应用作自动锁定条件。
