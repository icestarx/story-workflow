# 阶段 0 核心参考资料包

项目初始化时在同一 Canon 快照下读取以下 10 份资料。它们可以并行查阅，但必须在 00-project/global-framework-checklist.md 记录适用性；不适用也要说明原因。

| # | 资料 | 初始化用途 |
|---:|---|---|
| 1 | project-files.md | 文件职责、提交权和目录布局 |
| 2 | parameter-calculator.md | 字数、章节、卷数与容量基线 |
| 3 | canon-schema.md | 事实 ID、状态、可见范围与版本 |
| 4 | chapter-contract.md | 章节细纲和正文锁定条件 |
| 5 | volume-contract.md | 全书、长线和卷纲最低结构 |
| 6 | context-contract.md | 章节最小上下文和显式 Canon 引用 |
| 7 | quality-rubric.md | S1–S4 与四层质量门禁 |
| 8 | parallel-execution.md | 候选并行、串行合并和快照纪律 |
| 9 | genre-packs.md | 题材承诺、常见风险与混搭边界 |
| 10 | craft-patterns.md | 场景、钩子、爽点、反转和防重复工具 |

这不是让模型把十份资料原样复述；应将适用规则写进 workflow-config.json、frameworks.md、style-card.md 或检查清单。资料与项目选择冲突时，以用户确认的项目选择为准。
