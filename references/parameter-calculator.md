# 篇幅参数

scripts/calculate_parameters.py 输出的是起步规划，不是剧情质量的硬公式。根据题材、更新节奏与场景密度调整单章字数，再重新计算。

## 使用

    python scripts/calculate_parameters.py --total-words 800000 --genre 悬疑

可用 --words-per-chapter 明确指定单章目标；可用 --chapters-per-volume 调整卷的平均章节数。输出 JSON 中的 volume_ranges 可直接填入 03-outline.md。

## 默认单章字数

| 题材 | 默认字数 |
|---|---:|
| 仙侠、玄幻、奇幻 | 4000 |
| 悬疑、都市、科幻 | 3500 |
| 言情 | 3000 |
| 其他 | 3500 |

计算器采用向上取整，确保计划容量不低于目标总字数。短尾卷不是错误；若末卷过短，应该依据真正的卷级转折重分卷，而不是用无关剧情填满。

## 调整信号

- 一卷没有独立承诺和状态变化：合并或重构卷，不只改变章数。
- 单章总在超出目标 30% 以上：拆分事件或提高目标字数并同步更新计划。
- 伏笔账本超过可追踪能力：减少新伏笔、安排回收，或缩短回收窗口。
- 配角持续无目标或不影响因果：合并角色或收缩支线。
